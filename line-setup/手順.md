# 結婚式 公式LINE の作り方（所要 30〜40分）

ゲストが友だち追加すると、**名前を送るだけで自分の卓と席番号が返ってくる**公式アカウントです。
当日のスケジュール・会場への行き方・写真共有もここから案内します。

作るものは全部できています。増田さんにお願いするのは **①アカウント作成** と **②設置** だけです。

---

## 全体像

```
ゲスト ──友だち追加──▶ LINE公式アカウント（新規・結婚式専用）
                            │ Webhook
                            ▼
                     Apps Script（LineBot.gs）
                            │ 読む
                            ▼
              結婚式スプレッドシート「席次表2」「招待リスト」
                            │ 書く
                            ▼
                      「LINE登録者」シート
```

席は **席次表2 を毎回読む** ので、席を入れ替えたら返答も自動で変わります。

## ステップ1　LINE公式アカウントを作る（約10分）

> ⚠️ `~/.line-notify` にある既存のLINEチャネル（表示名「Claude」/ @890kkyvm）は
> 増田さんの業務通知専用です。**絶対に使い回さないでください。**
> ゲストの発言がそのチャネルのWebhookに流れ込み、`bridge.py` がコマンドとして実行してしまいます。

1. https://entry.line.biz/start/jp/ を開く
2. LINEアカウントでログイン（**個人のLINE**でOK）
3. アカウント情報を入れる
   - アカウント名：`増田家・加藤家 結婚式`（あとから変更できます）
   - 業種：`個人` → `個人（その他）`
   - 会社・事業者の所在国：日本
4. 作成が終わったら **LINE Official Account Manager** が開きます

### プロフィールを整える
- アイコン：前撮りの写真を1枚
- 背景画像：会場や二人の写真
- ステータスメッセージ：`2026.11.22 伊勢山ヒルズ`

## ステップ2　Messaging API を有効にする（約5分）

1. LINE Official Account Manager → 右上 **設定** → 左メニュー **Messaging API**
2. **Messaging APIを利用する** を押す
3. プロバイダーを選ぶ（なければ新規作成。名前は `増田家・加藤家` など）
4. 表示された **チャネルID / チャネルシークレット** の画面から
   **LINE Developers** に移動する
5. LINE Developers → 該当チャネル → **Messaging API設定** タブ
6. 一番下の **チャネルアクセストークン（長期）** → **発行** → コピーして控える

> このトークンはパスワードと同じです。人に見せない・チャットに貼らないでください。

## ステップ3　応答の設定（約3分）

LINE Official Account Manager → **設定** → **応答設定**

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| 応答モード | **Bot** | 自動で返すため |
| あいさつメッセージ | **オフ** | Apps Script 側で送ります（二重送信を防ぐ） |
| 応答メッセージ | **オフ** | オンだと定型文と自動返信がぶつかります |
| Webhook | **オン** | ここが本体です |

※ 画面の文言はLINE側の更新で変わることがあります。
　「Webhookをオン」「応答メッセージをオフ」の2つが合っていれば大丈夫です。
※ 手動で返信したい場面（名前が照合できなかった人への連絡など）は、
　LINE公式アカウントアプリのチャット機能から返せます。
　併用の可否は画面で確認してください。できない場合は、
　その人の個人LINEへ直接連絡するのが確実です。

## ステップ4　Apps Script を置く（約10分）

1. 結婚式スプレッドシートを開く
   https://docs.google.com/spreadsheets/d/10QQrOyDKassdp7K3qd7ewaxNORoqUj8ufDwUrDnmmj8/edit
2. **拡張機能 → Apps Script**
3. 既存の招待状フォーム用スクリプトとは **別のファイル** として追加する
   - 左の「ファイル」の **＋ → スクリプト** → 名前を `LineBot`
   - `apps-script/LineBot.gs` の中身を丸ごと貼り付けて保存
4. 左メニュー **プロジェクトの設定** → 一番下 **スクリプト プロパティ**
   - **スクリプト プロパティを追加**
   - プロパティ：`CHANNEL_ACCESS_TOKEN`
   - 値：ステップ2で控えたトークン
   - **保存**
5. 動作確認：エディタ上部の関数選択で `test_lookup` を選んで **実行**
   - 初回は権限の承認が出ます（自分で作ったものなので許可して大丈夫です）
   - **実行ログ**に「志佐陽 様のお席をご案内します。A卓（席番号 A2）」と出れば成功
6. **デプロイ → 新しいデプロイ**
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - デプロイ → 出てきた `https://script.google.com/macros/s/.../exec` をコピー

## ステップ6　リッチメニューを登録する（約2分）

ターミナルで、トークンを環境変数に入れてから実行します。

```sh
cd "/Users/user/Desktop/結婚式/wedding-invitation/line-setup"
python3 richmenu.py --upload
```

トークンは `~/.wedding-line/token` から自動で読みます（設定済み）。

`richMenuId = ...` と出れば成功です。LINEのトーク画面の下に5つのボタンが出ます。

| スケジュール | （見出し） | アクセス |
| --- | --- | --- |
| **席次表** | **御祝儀・お振込状況** | **写真＆動画共有** |

まん中の上は「WEDDING RECEPTION」の見出しなので、押しても何も起きません。

絵柄は `line-setup/richmenu.png` をそのまま使います。差し替えるときは、
同じ **2500×1686** のPNGを同じ名前で置いてください。
LINEは1MBまでなので、送る直前にスクリプトがJPEGへ落とします（`richmenu-send.jpg`）。

`--upload` なしで実行すると、送信用の画像とタップ領域だけを表示して確認できます。
絵柄の枠を動かしたときは、`richmenu.py` の `TILES` の座標も直してください。

## ステップ7　料金プランを選ぶ（重要）

| プラン | 月額 | 無料配信数 |
| --- | --- | --- |
| コミュニケーション | 0円 | 200通 |
| ライト | 5,000円 | 5,000通 |

**配信1通 = 1人分** です。ゲスト65名に5回配信すると 325通 で、無料枠を超えます。

- **おすすめ：11月だけライトプラン（5,000円）**。12月に無料プランへ戻せます。
- 無料のままでいく場合は、配信を **3回まで**（前日・当日朝・当日夜）に絞ってください。

> 「名前を送ったら席が返る」自動返信（応答メッセージ）と、あいさつメッセージは
> **何通送っても無料**です。配信回数だけが課金対象です。

## 二次会の扱い

**二次会にご招待していない方がいます。** そのため、
公式LINEの案内ページ・リッチメニュー・全員向けの配信文からは
二次会の記述をすべて外してあります。

二次会のご案内は `二次会のご案内` という専用の台本から、
招待リストで二次会＝出席の方にだけ届きます（現在 33 名）。
**この台本を `--target all` のように全員へ送らないでください。**

なお、披露宴は欠席で二次会だけご出席の方（山田隆太郎様）は
席次表2に載らないため、名前を送っても席が引けません。
「LINE未照合」シートに記録されるので、個別にご連絡ください。

## 当日までの配信

台本は `messages.json` に入っています。送る前に必ず下見してください。

```sh
cd "/Users/user/Desktop/結婚式/wedding-invitation/line-setup"
python3 broadcast.py --list            # 台本の一覧
python3 broadcast.py 前日 --dry-run    # 宛先と本文を確認（送らない）
python3 broadcast.py 前日 --send       # 実際に送る
```

| 台本 | 送る日 | 宛先 |
| --- | --- | --- |
| **事前振込のお願い** | **11/11** | 全員（振込締切が11/13のため最優先） |
| 1週間前 | 11/15 | 全員 |
| 二次会のご案内 | 11/20 | **二次会にご招待した方のみ** |
| 前日 | 11/21 | 全員 |
| 当日朝 | 11/22 朝 | 全員 |
| お開き直後 | 11/22 14:30頃 | 披露宴出席者 |
| 当日夜 | 11/22 20:00頃 | 全員 |

`【ここに…】` が残っている台本は送信をブロックします。先に `messages.json` を埋めてください。
埋めるのは、**前日の天気**、**BGMプレイリストのURL**、**共有アルバムのURL** の3つです。

## ゲストが送れることば

| 送ることば | 返ってくるもの |
| --- | --- |
| フルネーム（例：増田和也） | 卓・席番号 |
| 席、せき、座席 | もう一度お席を案内 |
| 流れ、スケジュール | 当日の流れのページ |
| 行き方、アクセス、地図 | 駅からの案内ページ |
| 写真、動画、アルバム | 共有アルバム（URL未設定なら「準備中」） |
| 振込、ご祝儀、口座 | 事前お振込の口座と締切 |
| 質問、服装、持ち物、ヘアセット | よくある質問のページ |
| 受付、チェックイン、着きました | お礼のメッセージ＋到着時刻を記録 |
| メニュー、ヘルプ | 使い方の一覧 |

照合できなかった発言は **「LINE未照合」シート** に自動で溜まります。当日までに時々見てください。

## お振込状況の照会

ご祝儀ページ（`line/gift/`）で、ゲストがお名前を入れると
「確認済み」「まだ確認できていません」「当日受付」のどれかが出ます。

**入金を確認したときの手順**

1. スプレッドシート `招待リスト` の **U列「入金確認」** にチェックを入れる
   （日付や金額を残したいときは V列「入金メモ」へ。例: `11/12`）
2. ターミナルで反映する

```sh
cd "/Users/user/Desktop/結婚式/wedding-invitation"
python3 line/sync_payment.py
git add -A && git commit -m "入金状況を更新" && git push
```

公開まで1〜2分かかります。

**氏名は公開していません。** 公開される `line/payment.json` に入るのは、
お名前を正規化してソルトを付けたハッシュだけです。中身は12桁の英数字が並ぶだけで、
ファイル単体からお名前は分かりません。金額も入れていません。

旧字（髙・邊・瀨など）、敬称、スペース、カッコ書きは自動で吸収します。
お呼び名や旧姓は `LINE別名` シートに足しておくと引けるようになります。
