■ 回答をスプレッドシートに集約するための設定手順
（kazuya.msd.20282@gmail.com でログインした状態で行ってください）

1. Google スプレッドシートを新規作成する
   https://sheets.new を開き、名前を「結婚式 出欠回答」などにする

2. スプレッドシート上部メニューから
   [拡張機能] → [Apps Script] を開く

3. 開いたエディタのデフォルトコード（Code.gs の中身）を全て削除し、
   同じフォルダにある Code.gs の内容を丸ごと貼り付けて保存する
   （Ctrl+S / Cmd+S）

4. 右上の [デプロイ] → [新しいデプロイ] をクリック
   - 種類の選択（歯車アイコン）→ [ウェブアプリ] を選択
   - 説明：任意（例: 招待状フォーム）
   - 次のユーザーとして実行：自分（あなたのアカウント）
   - アクセスできるユーザー：全員
   - [デプロイ] をクリック

5. 初回は権限の承認を求められます
   「承認」→ Google アカウントを選択 →
   「このアプリは Google で確認されていません」と出た場合は
   [詳細] → [（プロジェクト名）に移動（安全ではないページ）] → [許可]
   ※自分で作成したスクリプトなので問題ありません

6. 発行された「ウェブアプリのURL」（https://script.google.com/macros/s/.../exec）
   をコピーする

7. assets/app.js を開き、以下の行を書き換える
   const GAS_URL = 'YOUR_GAS_WEB_APP_URL_HERE';
   ↓
   const GAS_URL = 'コピーしたURL';
   （3バージョン共通のファイルなので ここ1か所だけでOK）

8. index.html をどこかにホスティングする（下記いずれか）
   - GitHub Pages（無料・簡単）
   - Google サイト（Google アカウントのみで完結）
   - Netlify / Vercel（無料枠あり）
   ローカルで開くだけ（ダブルクリック）でも動作確認は可能ですが、
   ゲストに配布するURLとしては上記いずれかでの公開が必要です。

■ 補足
・回答は「結婚式 出欠回答」スプレッドシート内の「回答一覧」シートに
  自動で追記されます。
・添付写真は Google ドライブ内に「結婚式_ゲスト写真」フォルダが自動作成され、
  ゲストごとのサブフォルダに保存されます。スプレッドシートの「写真リンク」列に
  各写真の閲覧リンクが記録されます。
・振込先は index.html の bank-card 内に記載しています
  （みずほ銀行 本郷支店(075) 普通 4179333 マスダ カズヤ）。
・「招待状の種類」列には 全体版 / 一次会のみ / 二次会のみ が記録されます。
  この列を追加したため Code.gs を貼り直して再デプロイしてください
  （見出し行はスクリプトが自動で直します）。
・Code.gs を修正した場合は、再度 [デプロイ] → [デプロイを管理] →
  編集(鉛筆アイコン) → バージョン「新バージョン」→ [デプロイ] で反映してください
  （URLは変わりません）。
